# Web Scraping with Scrapy

A collection of examples demonstrating web scraping techniques using Python's Scrapy framework.

The repository covers the following topics:

- Parsing HTML documents with Scrapy Selectors
- Extracting data using XPath and CSS selectors
- Retrieving and analyzing webpage content
- Creating Scrapy spiders
- Following links and crawling multiple pages
- Extracting structured data
- Exporting scraped results to JSON files
